# Ильсияр Тухватшина · Норма

Статический frontend на HTML/CSS/JavaScript, GitHub Pages, домен **ilsiyar.ru**.
Существующий FastAPI backend формы — **ilsiyar-api.onrender.com**.
CNAME, настройки Pages и Telegram-интеграция сохранены.

## Локальный запуск

Открывайте сайт через HTTP, не через `file://`.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload
```

- Главная: http://127.0.0.1:8000/
- Каталог: http://127.0.0.1:8000/objects.html
- Страница объекта: http://127.0.0.1:8000/property.html?id=ID

В локальном окружении форма обращается к `/api/lead`.
На публичных доменах — к `https://ilsiyar-api.onrender.com/api/lead`.

В корне backend должен быть приватный `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Секреты используются только сервером. Не добавляйте `.env` в Git, frontend или каталог данных.
Для просмотра без backend: `python -m http.server 8766 --bind 127.0.0.1`. Отправка формы в таком режиме недоступна.

## Структура

- `index.html` — главная, услуги, специалист, этапы, отзывы, контакты и форма.
- `objects.html` — поиск, фильтры по типу, городу и цене, сортировка.
- `property.html?id=ID` — фотографии, характеристики, статус и обращение по объекту.
- `styles.css` — единая дизайн-система и адаптивность.
- `script.js` — общие компоненты, каталог, взаимодействия и отправка формы.
- `assets/data/catalog.json` — единственный публичный источник объектов и отзывов.
- `assets/fonts/` — локальный Manrope с кириллицей и лицензия OFL.
- `assets/vendor/` — локальная фиксированная Motion 14.7.1 и лицензия MIT.
- `app.py` — прежний обработчик заявок; добавлены только маршруты двух новых HTML-страниц и алиас `/index.html` для локального просмотра.

Контакты централизованы в `SITE_CONFIG` в `script.js`. HTML содержит те же реальные ссылки для работы без JavaScript.
Настоящий портрет: `assets/images/photo_2026-08-23_15-43-49.jpg`. Оригинал не изменён.

## Как добавлять реальные объекты

`assets/data/catalog.json` содержит `schemaVersion: 1`, массивы `properties` и `reviews`.
Пока оба пустые: подтверждённых предложений и отзывов не предоставлено. Демоданных в публикации нет.

Каждый элемент `properties`:

| Поле                   | Формат                                                              |
| ---------------------- | ------------------------------------------------------------------- |
| id                     | Стабильный уникальный идентификатор: a–z, 0–9, дефис, до 80 знаков  |
| published              | true — опубликован; false — скрыт из списка и страницы              |
| title                  | Название, до 180 знаков                                             |
| type                   | Тип недвижимости                                                    |
| city                   | Город, до 100 знаков                                                |
| district, address      | Необязательные район и адрес                                        |
| status                 | active, reserved или sold                                           |
| price                  | Число в рублях либо null для «Цена по запросу»                      |
| area                   | Площадь в м², число                                                 |
| rooms, floor, landArea | Необязательные комнаты, этаж и участок в сотках                     |
| description            | Обычный текст, не HTML                                              |
| featured               | true — приоритет на главной; показываются до 3 непроданных объектов |
| photos                 | Массив объектов с полями src и alt                                  |

Фото — реальные файлы на том же домене, например в `assets/images/`; допустимы jpg, png, webp, avif.
Первое фото — обложка. Желательно экспортировать фотографии в webp/avif с достаточным разрешением и разумным весом; не менять оригиналы без необходимости.
Снятие с публикации: удалить объект из публичного JSON. `published: false` скрывает интерфейс, но **не закрывает доступ к данным**: репозиторий и JSON публичны. Не хранить здесь черновики, закрытые адреса и неподтверждённые сведения. Статус `sold` можно оставлять только для согласованного публичного архива.

Контекст выбранного объекта передаётся через ID в адресе формы. Название, ID и ссылка добавляются в `comment` существующего API. Персональные данные в URL и browser storage не сохраняются.
Интерфейс безопасно выводит текст каталога; разметка из данных не исполняется.

## Отзывы

Поля: `name`, `transaction`, `text` и/или `image` (локальный путь), `published: true`, `verified: true`.
Публиковать только реальные отзывы с разрешением клиента.
При пустом массиве раздел и пункт «Отзывы» не отображаются. От трёх отзывов появляются кнопки горизонтальной прокрутки.

## Заявки и проверка

Контракт API сохранён: name, phone, city, requestType, comment, source, consent, website.
Антиспам, серверная валидация и отправка в Telegram не изменены.

Frontend не показывает успех при пропущенном запросе. Повтор в течение 60 секунд показывает отдельное уведомление «Повторная заявка не отправлена». Успех возможен только после HTTP success и `ok: true`.
При недоступности сервиса остаётся прямая ссылка MAX. Если запрос прерван по таймауту, статус честно сообщает, что доставка не подтверждена.
Без JavaScript кнопка отправки неактивна; контакты доступны.

Для автоматизированной проверки перехватывайте `**/api/lead` в браузере и возвращайте тестовые ответы. Не отправляйте тестовые заявки в рабочий Telegram.
Тестовый каталог подставляйте через перехват `**/assets/data/catalog.json`, не добавляя демонстрационные объявления в публичные данные.

Анимации используют Motion и прогрессивные View Transitions: без поддержки остаётся обычная навигация. При `prefers-reduced-motion` эффекты отключаются.
Поисковики/социальные роботы без JavaScript видят общие метаданные страницы объекта; для индивидуальных OG-карточек в следующем этапе нужен статический генератор страниц или серверный рендеринг.

## Следующий этап: защищённое управление

Публичный JSON — формат выдачи, не система хранения секретов и не админка.
Для CMS нужны серверная авторизация, защищённые CRUD/upload endpoints, постоянная база и хранилище изображений в согласованной инфраструктуре, резервные копии и контроль прав.
CMS должна сохранять эту схему либо выдавать совместимый JSON. До подключения изменения вносятся через проверенный Git-коммит.

Исследование 16 кандидатов от 28.10.2026 хранится локально **вне этого репозитория**. Все кандидаты остаются без разрешения на публикацию. Для импорта нужны подтверждение актуальности, принадлежности, параметров, разрешение на размещение и права на фотографии. Не скачивать фотографии объявлений по факту их доступности.

Предпочтительный источник синхронизации — разрешённый владельцем экспорт CRM или приватный XML-фид. Сервер импортирует его в закрытые черновики; публичный JSON получает только утверждённые поля. XML-размещение Яндекса/Авито не предоставляет права копировать чужие объявления. Доступ к API и ключи хранятся исключительно на сервере.

## Визуальная система и взаимодействия — 28.10.2026

Монохромная система: чёрный, графит, тёплый белый и сдержанные детали шампань; локальный Manrope. Оригинальный портрет с естественным фоном находится в отдельной прямоугольной рамке. Hero разделён на светлую текстовую и графитовую фотографическую части; раздел о специалисте оформлен как тёмный редакционный разворот. Интерьерных фонов, вырезанного силуэта и декоративных иллюстраций нет.

Тёмная glass-навигация использует движущуюся контрастную подложку и отражение, следующее за курсором. CSS hover/focus работает независимо от Motion. Motion.animate управляет вступлением, подложкой, отражением, появлениями разделов и направленным выходом/входом этапов. Этапы оформлены типографикой, номером и линией прогресса; скрытые панели недоступны фокусу. Кнопки используют CSS-блик, подъём и движение SVG-стрелки. Все эффекты учитывают prefers-reduced-motion.

Навигация меняет размеры после 72 px прокрутки. Подложка следует за hover, фокусом и текущим разделом. Якоря `#buy` и `#sell` открывают соответствующую вкладку единого раздела услуг; заголовки учитывают высоту шапки. Этапы работы показываются в одной панели стабильной высоты: стрелки, четыре переключателя, клавиатура и горизонтальный свайп. Автопрокрутки нет. Motion управляет хореографией; при его недоступности все переключатели работают. Без JavaScript тексты всех услуг и этапов остаются доступны.

### Категории и ссылки каталога

`objects.html?category=house` открывает каталог домов. Допустимые значения: `apartment`, `newbuild`, `house`, `land`, `commercial`, `storage`. Пустое значение — все объекты. Поиск (`q`), город (`city`), максимальная цена (`price`) и сортировка (`sort`) сохраняются в URL. Сброс и история браузера поддерживаются даже при пустом каталоге.

Для новых объектов рекомендуется поле `category`: apartment / house / land / commercial / storage. Старое человекочитаемое `type` сохранено и сопоставляется с категориями. Новостройка — отдельный признак `market: "newbuild"` (также поддерживается `isNewBuild: true`), а не несовместимый с квартирой тип. Комнаты и иные типы остаются в общем каталоге, если отдельная категория не указана.

Обращение из пустой категории передаёт `category` в ссылке формы; выбранная категория добавляется в `comment` существующего API. Это не меняет backend-контракт. Объект, услуга и категория остаются различимыми, контекст можно убрать перед отправкой.
