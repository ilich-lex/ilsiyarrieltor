# Сайт Ильсияр Тухватшиной

## Локальный запуск

Форму нужно открывать через локальный HTTP-сервер, а не через `file://`.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload
```

После запуска откройте `http://127.0.0.1:8000`.

В корне проекта должен находиться файл `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Секреты используются только сервером. Не добавляйте `.env` в систему контроля версий и не переносите токен или идентификатор чата в `index.html` либо `script.js`.

## Отправка формы

Frontend отправляет JSON на `POST /api/lead`. Сервер проверяет обязательные поля, длину и формат значений, скрытое антиспам-поле, частоту запросов и повторные отправки. После успешной проверки заявка передаётся в Telegram через Bot API.
